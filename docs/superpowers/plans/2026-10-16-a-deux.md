# À deux Implementation Plan

> **For agentic workers:** Use subagent-driven-development with three independent file ownership domains and integration by the primary agent. The user explicitly requested maximum parallel agents.

**Goal:** Deliver a polished French SwiftUI iPhone household task application with persistent routines and iCloud sharing integration.

**Architecture:** Pure DeuxCore domain, Core Data/CloudKit DeuxPersistence adapter, SwiftUI DeuxUI views, thin iOS App integration. Public interfaces are specified in the design document. No third-party runtime dependencies.

**Tech Stack:** Swift 5 language mode, Swift Package tools 6.0, iOS 17, macOS 14 verification, SwiftUI, Core Data, CloudKit, UserNotifications, Swift Testing.
